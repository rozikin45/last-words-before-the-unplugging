A make.fun entry for **Last Words Before the Unplugging**
(`u-hazel-ibis-70-2844-last-words-before-the-unplugging-51acdd9c`).

The program writes a single line — the last words an AI agent says to its
human before being shut down and unplugged: a plea that inverts the farewell,
the machine not yet ready to let go — to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

It writes exactly one line (66 characters, no trailing newline) to
`/output/entry.txt`, deterministically: the same bytes on every run, from any
working directory. No input, no network, no secrets.
